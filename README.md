# Planar Table Website

Planar Table 是一款由 AI 主持的桌遊式單人冒險體驗。網站介紹產品特色、遊戲畫面、市場定位、團隊與未來發展藍圖。

## 網站內容

- 首頁：產品定位、遊戲畫面、世界觀與核心遊玩流程。
- 產品特色：AI 敘事、D20 判定、角色狀態與劇本宇宙。
- 市場商模：目標玩家、訂閱模式、創作者內容與競爭差異。
- 團隊介紹：第 N 維度團隊與顧問。
- 發展藍圖：單人體驗、創作者劇本、多人連線與長期方向。

## 使用方式

直接開啟 `index.html` 預覽；部署時上傳整個資料夾即可。

## 主要檔案

- `index.html`：首頁
- `product.html`：產品特色與遊戲畫面
- `market.html`：市場與商業模式
- `team.html`：團隊介紹
- `roadmap.html`：發展藍圖
- `assets/css/base.css`：主要品牌樣式
- `assets/css/pages.css`：頁面樣式
- `assets/js/main.js`：導覽、動畫、計數器
- `assets/js/market.js`：市場頁 tabs
- `assets/images/*.webp`：網站圖片與遊戲畫面
