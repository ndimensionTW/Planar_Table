Product / Interface

把 AI 對話重新包裝成一張「可被操作」的冒險桌。

Planar Table 的核心不是聊天，而是讓每一次輸入都能被規則、狀態、物品與劇情同步承接。新版產品頁以「介面就是遊戲桌」作為主視覺。

Dual Engine

右手寫故事，左手守規則：AI DM 不再同時當小說家與計算機。

N

敘事引擎 Narrative Core

負責場景氣味、NPC 語氣、玩家行動後果與分支敘事。它接受「規則層已確認的結果」，再轉化成具沉浸感的文字。

  • 高自由度自然語言輸入
  • NPC 對話與氣氛生成
  • 繁中語氣與在地文本調校
擲骰結果狀態落盤敘事回寫
R

規則引擎 Rule Kernel

負責 D&D 5e 角色資料、HP、物品、技能檢定與資料庫保存，降低大型語言模型在數值上自說自話的風險。

  • 骰子檢定與能力值計算
  • 物品與金幣資料一致性
  • 角色進度與死亡豁免保存
MVP Screens

直接使用你們的實機畫面，把官網與產品本體接起來。

依照附檔截圖，產品核心介面是手機優先的三分頁：冒險、狀態、功能。新版官網不再只放示意圖，而是把 MVP 真實畫面放進產品頁，讓評審與使用者一眼看懂目前能玩什麼。

MVP 已具備的可展示能力

  • 互動式創角嚮導：使用者用較低門檻完成角色建立。
  • 劇本選擇器：福爾摩沙傳奇、官方劇本、自訂開場與隨機劇本可承接不同玩家。
  • 混合式物品管理：AI 生成物品後，仍可被規則層記錄與使用。
  • 角色儀表板：HP、等級、金幣、六圍屬性、持有物品與狀態同步顯示。

對外最值得強調的一句話

「ChatGPT 可以講故事；Planar Table 會記得你還剩幾滴血。」

這句能快速區分通用 AI 與產品型 AI 遊戲：通用 AI 生成文本，Planar Table 則以資料結構維持遊戲後果。
